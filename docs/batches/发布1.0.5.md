- **边界（明确不做）**：不建 GitHub Release（不打 tag、不产发布 zip）；不改 `public/manifest.json` 的 `3.1.0`；不补 README 用户手册（台账 #4 另行排期）；不改任何运行行为。
- **验收**：`package.json` 的 `version` 读出为 `1.0.5`；`node --check` 不受影响；`.gitignore` 含 `.thincoder/`；`git status` 无临时目录残留。

### 三条上抛的裁决

**一、本批没有需求档——按上面五要素就地补齐，不单建需求档。**

理由：本批要求两条、边界四条，全部落在本节，比再开一份需求档更短、更不会与本节对峙。上一批的需求档已覆盖真正的产品面变更，本批只是收尾。

**二、本批不建 GitHub Release。**

这是对外动作——会把 tag 与发布包推到 GitHub，属用户的决定，不是工程批次的副产物。因此**必须写清后果**：

> 设计席从 `server/update.js` 读出：当前版本只读 `package.json`；新版号来自 GitHub「最新一条 Release」的 tag；下载包只认该 Release 里匹配 `.zip` 的资产。**所以本批做完、版本号改成 1.0.5 之后，用户侧仍然收不到更新**——除非另建一个 1.0.5 的 Release 并挂上 zip。

这条后果要原样告诉用户，不能让它埋在文档里。建不建 Release、什么时候建，由用户定。

**三、`public/manifest.json` 的 `3.1.0` 不动。**

它是 OBR 扩展清单的版本，与程序版本 `1.0.4` 是两条线。本批不改插件的对外契约，也就不动这个号。用户的意见我会在交付时一并问清——若希望 OBR 侧也认作新版本，那是一个单独的小动作，不夹在这里。

实施席的实现也符合裁决要点：内容不扫，但目录存在仍逐个点名告警，退出码不受影响。真泄漏仍拦——单测里有一个用例专门验这条。

### 机制设计（摘要，判据与契约在设计档）

发版 = 三件事：`package.json` 的 `version`、GitHub Release 的 tag、Release 挂的 `.zip` 资产。自动更新读「最新一条 Release」的 tag 当新版号、zip 当下载包，本地 `package.json` 当当前版本；版本比较前剥掉 `v` 前缀。

- 版本单一来源 = `package.json`。不新增第二份版本文件。
- 发布前自检 = `npm run check-release`，退出码 0 才算能发。
- 发布包解压后是程序目录本身，或只多套一层含 `package.json` 的目录。
- 启动替换范围固定 `public` / `server` / `scripts` / `img` 加根目录五个文件；`runtime/` 与 `data/` 不动。

接口契约与逐条依据见设计档 §1 与 §2。

### 关键决策

- 版本号只写 `package.json` 一处：读取点只有 `currentVersion()`，两处版本号迟早不同步，而不同步时自动更新会认错新版。
- tag 沿用 `v<version>` 形态：与既有 `v1.0.0` / `v1.0.2` / `v1.0.4` 同形，且 `cmp()` 会剥掉 `v`。

- `public/manifest.json` 的 `3.1.0` 不随本批动：它是扩展清单版本，与程序版本两条线。

#### 二、发布包构成（这是本批最重要的发现）

**工作区原本缺 `runtime/node.exe`。** `runtime/` 只有 `cloudflared.exe`(52.8MB)，而启动脚本的第一选择就是 `runtime\node.exe`——拿当时的目录直接打包，会做出一个「没装 Node 的用户双击跑不起来」的坏包。

判定上一个包装了什么的依据是压缩率实测：`node.exe` 88.3MB → 33.9MB，`cloudflared.exe` 52.8MB → 18.3MB，代码 0.68MB；两者相加约 55.4MB，与 v1.0.4 资产大小（58,091,309 字节 = 55.4MB）吻合，所以**上一个包两个运行时都在**。

处置：把系统 Node（v24.18.1，88.3MB）复制进包内 `runtime/node.exe`，补全运行时后打包。

最终包：43 个条目，51.5MB；顶层无多余目录；中文文件名原样（`一定要先看README！.txt`、`卸载.bat`、`点这个启动程序.bat` 均在）；包内 `package.json` 的 version 为 1.0.5；`runtime/` 含 node.exe(88.3MB) + cloudflared.exe(52.8MB) + LICENSE.node.txt。
