# 咕咕点歌台

一个 Owlbear Rodeo 的音乐播放插件。

支持本地音乐直接拖进来，或者粘贴 B 站链接，解析视频后提取音轨，告别 URL，哦耶！

玩家不能操作播放，也看不到歌单——再也不用担心他们看到歌单而被剧透！

可以把音乐按「探索」「战斗」之类分好类，不用担心正式开团找不到歌~

## 它怎么工作

没有中心服务器，不用注册账号，也没有任何公共后端。

```
你双击「点这个启动程序」
        ↓
服务跑在【你的电脑】上
        ↓
在 OBR 里建房间、装上插件 → 玩家进来就能听到
```

所以：

- **谁运行程序，服务就在谁的电脑上**；
- 安装地址是那台电脑启动时生成的，**每个人都不一样**。

朋友想用，他下载一份、双击他自己的程序就行——他的玩家连他，和你完全独立。不会有任何流量或文件跑到你这边。

> 这个地址只在你这台电脑运行时有效。

---

## 开始之前

- **不用安装任何东西**：运行环境和隧道程序都已经打包在压缩包里，解压双击就能用；
- **开团期间电脑不能关机或休眠**，否则音乐立刻中断；
- 玩家**什么都不用做**，不用装插件，也不用运行这个程序。

> 内置运行环境只支持 **Windows**。macOS / Linux 用户需自行安装 [Node.js](https://nodejs.org) 18+，然后运行 `./start.sh`。

## 安装

### 1. 启动终端

解压后双击 **`点这个启动程序.bat`**，等几秒，窗口里会出现安装地址：

```
  咕咕点歌台 已启动
  --------------------------------------------------

  ┌───────────────────────────────────────────────┐
  │ 扩展安装地址                                   │
  │                                               │
  │ https://xxxx-yyyy.trycloudflare.com/manifest.json │
  └───────────────────────────────────────────────┘

  安装方法：左下角三个点 → Extension → 右上角加号 → 粘贴上面的地址

  提示：这个窗口要一直开着；关掉或重启后地址会变，你需要重新复制地址安装。
```

> 第一次启动 Windows 可能弹出防火墙提示，选**允许**（否则玩家连不上）。

### 2. 开房间

在 Owlbear Rodeo 里创建一个房间，或者进入一个已经建好的房间——总之**你是房主的那个房间**。

### 3. 安装插件

复制终端窗口里那行地址，然后在 Owlbear Rodeo 里：

**左下角三个点 → Extension → 右上角加号 → 粘贴地址 → 确认**

现在左上角就有图标了。

---

## 放音乐

点左下角图标打开面板，切到「添加」：

- **本地音乐**：把 mp3 / m4a / wav 等文件拖进去，或点击选择；
- **B 站视频**：粘贴链接（如 `https://www.bilibili.com/video/BVxxxx`），自动只取音频。

传完回到「歌单」，**点歌名开始播放**，这就完事了！

## 常用操作

| 想做什么 | 怎么做 |
| --- | --- |
| 切歌 | 点歌单里的歌名，或用 ⏮ ⏭ |
| 单曲循环 | 可以循环播放一首曲子 |
| 给歌分类 | 歌单上方的分类标签；点 `＋` 新建（比如「城镇」「恐怖」），每首歌右边的文件夹图标可改分类 |
| 改歌名 | 点每首歌右边的铅笔，改标题和歌手（比如把「Track 03」改成「酒馆的余烬」） |
| 上传时自动归类 | 先选中某个分类再上传，歌会直接进那个分类 |
| 拖动进度 | 拖播放条，松手后所有人跳到同一位置 |
| 调整整体音量 | 设置 → 全房间音量（影响所有人），突然拖动可以吓他们一跳^-^ |
| 调整自己的音量 | 设置 → 我的音量（只影响自己） |
| 不让玩家看到歌名 | 设置 → 关掉「对玩家显示曲目」 |

## 玩家会看到什么

一个简洁的「正在播放」面板：封面、歌名、进度条，以及**自己的音量**。如果你不想让他们看到歌名也可以去设置里关掉——对b站链接尤其推荐，毕竟假如你用的b站链接放Araya，标题很有可能是“【边狱巴士】“谢谢你来找我....”Araya（阿赖耶）三生三世三千世界战 战斗音乐”——让玩家知道是别的游戏boss战音乐还是有点破坏沉浸感的。
- 如果出现「开启声音」的按钮，点一下就好——浏览器不允许网页自动出声。

## 常见问题（其实重新点开启动程序安装基本能解决）

### 玩家听不到声音

按顺序检查：

1. 你的终端窗口还开着吗？
2. 你的防火墙允许了吗？（第一次启动时会问）
3. 玩家点过面板上的「开启声音」吗？
4. 换房间或重启之后，你重新装过插件吗？

### 重启电脑后玩家就没声音了

因为你重启后地址变了，旧地址失效。在 OBR 里把扩展移除、用新地址重装一次即可。玩家那边不用动。

### 面板打不开 / 一片空白

先确认终端窗口还在运行；如果它已经关了，重新双击 `点这个启动程序.bat`。

### B 站链接解析失败

大会员 / 付费限定视频拿不到音轨，普通的免费公开视频都能用。

### 玩家说音乐卡顿

跟你和玩家之间的网络质量有关。可以让玩家关掉占带宽的程序，或确认不是用手机流量。

### 关掉终端会怎样？

音乐立刻停止，玩家掉线。这就是窗口要一直开着的原因。
